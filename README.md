# x-info

X/Twitter list intelligence skill for OpenClaw.

## Included skill

- `skills/x-list-digest`

## Purpose

When asked `帮我获取列表推文`, the skill is designed to:

1. fetch tweets from the configured X lists
2. deduplicate by `tweet_id`
3. analyze and summarize for a blockchain airdrop hunter / US trader
4. assign fixed tags
5. write Obsidian-compatible markdown notes
6. commit and push results to GitHub
